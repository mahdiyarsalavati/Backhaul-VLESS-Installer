# Backhaul VLESS Installer

Automated installer for [Musixal/Backhaul](https://github.com/Musixal/Backhaul).

It configures Backhaul on both Iran and foreign servers, provides automatic route-aware tuning, and can generate a ready-to-import VLESS + REALITY configuration. Manual configuration is also available.

## Install

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mahdiyarsalavati/Backhaul-VLESS-Installer/main/backhaul-universal.sh)
```

Run the same command on both servers and select the appropriate role.

Original project: [Musixal/Backhaul](https://github.com/Musixal/Backhaul)
